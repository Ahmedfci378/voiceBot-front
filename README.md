
# VoiceBot Frontend

Frontend interface for the AI Voice Chatbot.

This application provides a chat interface where users can interact with the AI using text or voice.

## Tech Stack

- Next.js
- React
- Socket.io Client
- Web Speech API
- Lucide React Icons

## Features

- Chat UI for user interaction
- Voice input using Speech Recognition
- Audio playback for AI responses
- Real-time communication with backend
- Session-based chat
